Steam AI Bot — это ИИ-бот для Steam Chat, написанный на Python. Бот работает как отдельный Steam-аккаунт и позволяет пользователям общаться с локальными нейросетями через Ollama. Поддерживается выбор разных моделей для каждого пользователя, просмотр установленных моделей, сохранение настроек в SQLite и управление через команды /models, /model, /current, /reset и /help. Проект рассчитан на Windows и Python 3.12.
