# VCI-BOT

**VCI** — это ИИ-бот для Steam Chat, написанный на Python. Он работает как отдельный Steam-аккаунт и позволяет пользователям общаться с локальными нейросетями через [Ollama](https://ollama.com/).

## Возможности

-  Общение с локальными ИИ-моделями через Steam Chat.
-  Выбор отдельной модели для каждого пользователя.
-  Просмотр списка установленных моделей Ollama.
-  Сохранение пользовательских настроек в SQLite.
-  Управление ботом с помощью команд:
  - `/models` — список доступных моделей.
  - `/model` — выбор модели.
  - `/current` — просмотр текущей модели.
  - `/reset` — сброс настроек.
  - `/help` — список доступных команд.

## Требования

- **Операционная система:** Windows
- **Python:** 3.12
- **Ollama:** установленная и настроенная локальная среда Ollama.

## О проекте

VCI-BOT объединяет Steam Chat и локальные языковые модели, позволяя использовать возможности искусственного интеллекта прямо в Steam без необходимости подключения к облачным API.
